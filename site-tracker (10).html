Cloud Sync (optional)
Point this at any JSON storage endpoint you control (e.g. a PocketBase or Supabase REST row, or a simple JSON-bin service) to keep this tracker's data in sync across devices, instead of manual Export/Import. Nothing is sent anywhere until you set an endpoint and press Push or enable auto-sync. Uploaded files stay local only — sync covers site data, not attachments. Before every push, this checks whether the cloud copy has changed since this device last synced (e.g. a colleague pushed from theirs) and asks before overwriting it — so two people syncing the same endpoint won't silently erase each other's work.
